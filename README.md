# Trabalho_Hash - Ester

No código hash_voos que foi implementado em C++ usa-se o tratamento de colisões de 'encadeamento externo', onde cada vez que o número de voo colide com outro numero de voo é criado uma lista encadeada de colisoes nessa posição, onde os valores inseridos nelas correspondem ao mesmo valor rash. Foi implementado função de cadastro de voo e busca.
